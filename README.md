# Aula-02---HTML-Avan-ando-com-IDE
Nesta aula, instalaremos o VS Code e usaremos o Emmet para criar páginas web. Aprenda a estruturar documentos HTML, configurar idioma, charset (UTF-8) e viewport para celulares. Pratique tags principais (títulos, parágrafos, imagens e links). Objetivo: Criar e estruturar sua primeira página web responsiva. Professores: 🥁🧙🏽‍♂️
